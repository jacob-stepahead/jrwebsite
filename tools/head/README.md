# The head

`assets/3d/head.glb` is generated by the scripts in this folder. Nothing is
hand-modelled and nothing comes from a stock asset: the head is sculpted in
code, then cut into flat planes for the faceted look.

## Rebuild

```bash
pip install numpy scipy scikit-image trimesh fast-simplification mapbox-earcut
python3 tools/head/build_head.py            # full quality, ~90 s
python3 tools/head/build_head.py --fast     # coarse grid, for quick iteration
```

## How it works

| File | What it does |
| --- | --- |
| `sdf.py` | Small numpy signed-distance toolkit (ellipsoids, capsules, smooth min/max). |
| `anatomy.py` | The sculpt: skull, brow, eye sockets and almond lids, nose, lips, jaw, ears, neck, turtleneck and shoulders. Landmarks are in centimetres; proportions follow the classical thirds. |
| `hair.py` | A hair volume shaped around the scalp, plus about 170 ribbon locks grown through a swept-back flow field. Along-lock position and a random seed are packed into vertex colours for the wind shader. |
| `build_head.py` | Marching cubes → decimation → [Variational Shape Approximation](https://www.cs.cmu.edu/~dcoeurjo/vsa/) into planar regions → GLB writer. Ambient occlusion is baked from the SDF. |
| `remesh.py` | Rebuilds each planar region as one clean polygon, with straight edges between corners, so facets read as sculpted planes. |

Vertex colour channels in the GLB: **R** = baked ambient occlusion,
**G** = facet variation (face) or position along the lock (hair), **B** = lock
seed (hair).

## Tuning

- Face shape: edit the landmark numbers in `anatomy.py` (for example `EYE_C`,
  the `jaw()` gonion and chin points, or the ellipsoids in `nose()`).
- Number of planes: the `k` argument in `build_part("head", …)` (currently 340).
  Fewer planes look more abstract; more look more detailed.
- Hairline and length: `HL_AZ` / `HL_EL` and `_grow_one()` in `hair.py`.
- Materials, lights, glass and bloom live in `js/head/scene.js`.

## Preview

With a static server running at the repo root (for example `npx http-server -p 8765`):

- `tools/head/preview.html`: clay turntable views
  (`?views=front,34,side&hair=0&debug=normal`).
- `tools/head/stage.html`: the real shaded scene, rendered deterministically
  (`?t=4&mx=0.3&my=0.1&glass=0.35`).
- `index.html?capture`: a frame-stepping mode used to export the preview video.
